# 公开提交范围

本次按用户要求公开整个 Jev 项目的源码、文档、研究记录、汇总报告和看板源码，排除模型与数据文件。发布快照与正在运行的原始工作目录分开整理，原始文件没有被删除。

包含：

- Python / JavaScript / TypeScript / React 代码、Notebook、脚本、配置及依赖锁文件。
- 实验报告、汇总指标、训练进度记录、数据与模型来源说明。
- 上游参考源码、许可证，以及已有的本地修改。

不包含：

- 模型权重、tokenizer 资产，以及各种模型导出格式。
- 原始/处理后数据、训练/开发/校准/测试集、逐题预测、浏览器轨迹和大型数据样本。
- 看板 `src/data.json`、构建产物、含题目数据的生成页面与离线导出。
- 虚拟环境、安装的依赖、缓存、浏览器个人资料、环境密钥和嵌套 Git 历史。

`source-manifest.json` 记录保留文件的 SHA-256、上游版本和排除文件的类别。README 中的示例与源代码里的单元测试夹具仍保留；它们是使用说明或代码测试的一部分。只含文档/准备代码的数据目录也会保留。

报告保持原实验记录，部分链接所指的数据文件和模型需要在本机恢复。此仓库不宣称能够仅靠已提交文件重现缺少权重或数据的模型评测，也未启动新的训练或更改现有结果。
