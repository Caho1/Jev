## 开发检查

预先按 ID 固定选取每个开发网站 1 个页面，共 4 页、1,020 个完整候选控件。初检如下：

| 指标 | 原始 Laya | 本轮微调 |
|---|---:|---:|
| Recall@1 | 0/4 | 0/4 |
| Recall@8 | 1/4 | 0/4 |
| Recall@24 | 2/4 | 1/4 |
| Recall@64 | 2/4 | 3/4 |
| MRR | 0.07539 | 0.02870 |

Recall@K 表示正确目标出现在模型前 K 个候选中的步骤比例。MRR 为正确目标倒数排名的均值。缺失目标计为失败，相同分数用稳定节点编号排序，不用答案破除平局。

4 页初检没有显示 Recall@24 改善，且不足以代表全部开发数据。因此保持检查点不变，扩展到 **全部 78 个开发步骤、24,787 个候选控件**。完整评测在独立目录 `../computer-use-grounding-cuda-v1-development/` 记录，不覆盖初检结果。
