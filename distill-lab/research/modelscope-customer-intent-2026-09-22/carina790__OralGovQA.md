OralGovQA：中文政务口语化问答数据集

数据集简介

OralGovQA 包含 8,246 条中文政务咨询问题，每条同时提供口语化表达和对应的正式书面表达，部分条目附带官方答复原文。

数据覆盖社会保障、户籍办理、住房、教育、企业开办等常见政务服务场景，经语言风格标准化处理后，贴近市民日常咨询的真实用词习惯，可用于政务问答、查询改写、意图分类等任务的评估。

数据来源

正式问题与答复原文来源于各级政府门户网站、政务服务网的公开问答与办事指南。口语化表达参照市民实际留言板中的日常咨询方式，涵盖直接询问、催促进度、代人咨询、不了解政策背景等常见对话情境。

数据采集时间跨度为 2020-2026 年，覆盖全国各省市政府公开信息与政务服务事项。

数据格式

JSONL 格式，每行一条记录：

```json
{
  "question_id": "oralgovqa_00001",
  "question": "疫情期间在老家待了大半年，四川那边的防疫政策到底有哪些？",
  "original_question": "四川省在疫情防控方面采取了哪些措施来保障人们的健康安全？",
  "intent": "政策依据",
  "answer": "四川省已建立常态化疫情防控机制，全面落实健康码管理..."
}
```

字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| question_id | string | 查询唯一标识 |
| question | string | 口语化日常咨询表达 |
| original_question | string | 对应的正式政策问题 |
| intent | string | 意图分类 |
| answer | string | 官方答复原文（部分条目，974/8,246） |

许可

本数据集仅限学术研究使用。
