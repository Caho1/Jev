# smalljev semantic-v9 measurement — mapping fixed before the run

Written 21 Sep 2026 before the full run. `isHeSatoshi/smalljev` revision
`65f74b49748f2663225a6fc68852c0a7d09fd0b9` supplies the Python package and
`isHeSatoshi/smalljev-semantic-v9` revision
`8e2bac7c4e922371c05899f4f000233e8096fee6` supplies a LoRA adapter and three
native decision heads for `openbmb/MiniCPM5-2B-Base`. Code, adapter and base are
declared Apache-2.0. The system has about 2.5B backbone parameters, makes no
generated-token call and returns native probabilities.

The frozen v1.2 set and scorer are unchanged. The entrant has a typed Python
interface, but no TypeSafe-compatible HTTP `/v1/systemone` server. Its own
previously published JevBench adapter fixes this mapping, which this repository
implements independently:

- state: strings pass verbatim; objects use stable JSON;
- question: the exact instruction followed by `Allowed answers and rubric:` and
  the complete rubric as JSON;
- choice: exact JevBench labels are the option spans and the native shared
  `OptionScorerHead` softmax is returned;
- noul: `no` and `yes` are semantic options, with the false/true criteria in the
  rubric, and the same native shared-head softmax is returned;
- score: the level descriptions are semantic options and their probabilities
  map back to exact integer level labels.

Inference is serial, one request at a time, with no option-order ensemble,
retry-based answer selection or fitted calibration. The author's 2,560-token
semantic input limit is retained. The endpoint condition and measured GPU are
recorded in the row. Cost is an estimate of $0.04 per million measured input
tokens and zero output tokens, the submitted reference basis; local or rented
execution is not an automatic Cost score of 100.

The published training summary reports 28,328 choice and 16,895 Noul examples.
The recoverable public training recipe explicitly calls v8 a “JevBench
hill-climb”, renders half of choice training in the JevBench request shape and
selects/boosts source families after public-benchmark evaluation. It says the
underlying dataset rows were selected from source splits or families disjoint
from its public evaluation items. This benchmark-directed use of public items
and source families is allowed and will be disclosed with the result. The exact
final training rows were not published, so absence of every exact public item
cannot be independently proved from the released checkpoint and summary alone.
